Keyword Lab · 시행일 2026-11-01

1. 수집하는 정보

Keyword Lab은 현재 운영자가 자기 PC에서 테스트 중인 도구로, 아직 다른 이용자의 개인정보를 수집하지 않습니다. 앞으로 다른 사용자에게 유료 서비스로 제공할 계획이며, 제공을 시작하기 전에 이 방침을 고쳐 수집 항목과 보관 기간을 알립니다. Google 계정으로 로그인하면 Google Ads API 접근에 필요한 인증 토큰만 받습니다.

2. 이용 목적

인증 토큰은 운영자 본인의 Google Ads 계정에서 키워드 아이디어와 검색량, 클릭당 비용, 경쟁도 같은 키워드 계획 데이터를 조회하는 데만 씁니다. 광고 캠페인을 만들거나 바꾸지 않습니다.

3. 보관과 제공

인증 정보와 조회 결과는 운영자의 PC에만 저장됩니다. 제3자에게 판매하거나 제공하지 않으며, 외부 서버로 보내지 않습니다.

4. Google 사용자 데이터

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 삭제와 접근 취소

운영자는 PC에 저장된 파일을 지워 언제든 데이터를 삭제할 수 있고, Google 계정 권한 페이지에서 접근 권한을 취소할 수 있습니다.
