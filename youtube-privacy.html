1. 수집하는 정보

YouTube Channel Tool은 운영자 한 명이 자기 PC에서 쓰는 도구이며, 다른 이용자의 개인정보를 수집하지 않습니다. 운영자가 Google 계정으로 로그인하면 YouTube API 접근에 필요한 인증 토큰을 받고, 운영자 본인 채널의 영상 정보와 통계를 읽습니다.

2. 이용 목적

인증 토큰은 운영자 본인 채널에 영상을 올리고 예약하며, 영상 정보와 채널 설정을 관리하고, 채널 통계를 읽는 데만 씁니다.

3. 보관과 제공

인증 토큰과 통계는 운영자의 PC에 저장됩니다. 판매하지 않습니다. 운영자가 쓰는 AI 작업 도구가 운영 보고서를 만들 때 채널 통계를 처리할 수 있으며, 그 밖의 제3자에게 제공하지 않습니다. 인증 토큰은 어떤 제3자에게도 제공하지 않습니다.

4. Google 사용자 데이터

Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 도구는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받는 YouTube API 서비스를 사용합니다.

5. 삭제와 접근 취소

운영자는 PC에 저장된 파일을 지워 언제든 데이터를 삭제할 수 있고, Google 계정 권한 페이지에서 접근 권한을 취소할 수 있습니다.
